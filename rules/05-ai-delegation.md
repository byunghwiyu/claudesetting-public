# 05. AI 작업 위임·리뷰 규칙

## 스킬·에이전트·자동화 신설 전 승인 규칙
반복 수동 업무를 발견해도 **즉시 스킬/서브에이전트/자동화/훅을 만들지 말 것**. 먼저 후보로 정리해 승인받는다.

### 후보 조건 (모두 만족 시에만 패키징 대상)
- 최소 2회 이상 발생했거나, 앞으로 반복될 가능성이 높고 반복 비용이 큰 작업
- 입력 / 절차 / 출력 / 종료 조건이 안정적인 작업
- 패키징했을 때 속도·품질·일관성·신뢰성이 실질적으로 개선되는 작업
- 기존 skills / custom agents / automations / hooks 로 충분히 커버되지 않는 작업

### 형태 선택 (가장 작은 적절한 형태)
- **Skill**: 재사용 가능한 워크플로우나 플레이북
- **Custom subagent**: 위임 가능한 한정된 전문 역할이나 조사 작업
- **Automation / Hook**: 정기 점검, 리포트, 리마인더, PreToolUse 가드
- **Extend existing**: 이미 있는 스킬/에이전트/훅을 확장
- **Skip**: 일회성·모호함·민감함·근거 부족·중복 가능성 높은 작업

### 보고 형식 (생성 전 필수)
- 반복 업무
- 근거와 날짜
- 빈도 / 신뢰도
- 추천 형태
- 생성할 가치가 있는 이유 또는 스킵 이유

**명시적 승인 전에는 스킬·에이전트·훅·자동화를 생성/수정/삭제하지 않는다.**

## 위임·리뷰
- 반복 오류는 실행 규칙의 자동 교정 루프에 따라 원인과 접근을 재검토한다.
- 위임은 사용자가 허용하고 현재 도구가 지원할 때만 수행한다. 특정 플러그인이나 슬래시 명령이 설치돼 있다고 가정하지 않는다.
- 새 모듈이나 구조 변경 후 독립 리뷰를 권장하되, 별도 에이전트 실행은 승인된 범위에 따른다.
